## English

- Code is licensed under Apache License 2.0 (`LICENSE`); this does not cover the model weights. Model weights (`model.safetensors`, `onnx/`, `coreml/`) are licensed under CC BY-NC-SA 4.0 (`LICENSE_MODEL`); commercial use requires separate permission.
- The visual encoder is initialised from [zenosai/MonkeyOCRv2-S](https://huggingface.co/zenosai/MonkeyOCRv2-S), whose code and weights are declared under Apache License 2.0 (`THIRD_PARTY_LICENSE_MONKEYOCRV2`). The encoder code in this package is an inference re-implementation with the same parameter names.
- Real training samples derive from [JustANormalTinkerer/animetext-ocr](https://huggingface.co/datasets/JustANormalTinkerer/animetext-ocr) (revision `9c70c6b`), declared under CC BY-NC-SA 4.0.
- The images of that dataset come from AnimeText ([arXiv 2510.07951](https://arxiv.org/abs/2510.07951)). The real kana glyphs used by the synthetic handwriting were also cut from AnimeText images and upscaled 4× with [Real-ESRGAN](https://arxiv.org/abs/2107.10833) (RealESRGAN_x4plus_anime_6B); this package does not contain those glyphs.
- Synthetic training data was generated by the project renderer. This package contains no training images, font files or AnimeText-OCR images.
- No image from the JMangaBench_Read candidate pool or benchmark was used for training.
- The 8 example crops in `samples/` are taken from [JMangaBench_Read v1.3](https://github.com/muscgab/JMangaBench_Read) (CC BY-NC-SA 4.0); the original works were published online by independent artists. File names are the box IDs in Read.
